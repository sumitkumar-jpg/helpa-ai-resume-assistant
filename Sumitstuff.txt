### Helpa – AI Resume Assistant

Description:

Developed Helpa, a full-stack AI-powered resume assistant that enables recruiters and hiring managers to interact with my resume through natural language. The application allows users to ask questions about my education, skills, projects, and experience, as well as upload job descriptions or sample resumes for AI-powered comparison.

The backend is built with FastAPI and integrates Groq's Llama 3.3 70B language model to generate accurate, context-aware responses. It extracts text from PDF, DOCX, and TXT documents and uses the uploaded content during conversations when relevant.

The frontend was built using HTML, CSS, and JavaScript, providing a chatbot-style interface with real-time messaging, file uploads, automatic scrolling, Enter-to-send functionality, and loading indicators. Communication between the frontend and backend is handled through REST APIs using JavaScript's Fetch API.

To support multiple users simultaneously, I implemented session-based conversation management, ensuring each user receives an independent chatbot with isolated conversation memory and uploaded documents. Refreshing the webpage automatically starts a fresh conversation without affecting other users.
